# 月度绩效填报

根据当期记录整理个人贡献，按实际表单生成填写稿或代填。最终提交由填报人完成。

## 收集输入

- 确认考核周期和工作记录。接受用户有权访问的链接、文件、截图或文字。团队表格有多个标签页、负责人或月份时，按用户给出的范围读取。
- 有人日字段时，确认总人日、已定的单项人日和允许的精度。业务线、部门、项目编号等以该表要求为准，沿用用户给出的默认归属和例外。自评如果有指标、字数或格式要求，按该表执行。
- 需要直接填表时，使用本人已登录并打开的填写页，或用户指定的表单入口。沿用对话中已提供的信息，先整理能确认的内容，再集中询问影响结果的缺项。源材料无访问权限时，接受同一批记录的导出、截图或摘录。

## 从记录到填写稿

1. 筛出考核周期内的工作，按交付目标合并重复周报。区分完成、推进和计划。写清个人承担了什么、实际交付了什么、目前进度如何。团队成果使用有依据的个人角色和协作表述。数字、结果、完成状态与记录保持一致。
2. 按表单实际字段组织。人日表通常按事项拆为多行，包含项目或业务线、事项、人日、小结。自评表可能要求按目标写产出、个人贡献、反思和改进计划。自评等级、评分及个人判断交由本人提供和确认，有缺项就标注待补。
3. 人日优先使用已确认值。获授权估分时，按交付范围与工作量分配剩余人日，保留已确认单项，按允许的精度核对合计。说明哪些值是估算。总额或单位冲突时请用户确认。没有人日字段的表单按其原字段填写。
4. 恢复填写时，先比对上次核对的内容与当前页面，补缺或改错，避免重复增加行。无法取得上一版时用原工作记录重建，并说明差异或待确认项。

## 填写与交接

- 直接操作前核对这是用户本人、本周期、指定流程的填写页。采用当前 Agent 已具备且授权的表单操作能力。操作前阅读 [平台与表单适配](references/form-adapters.md)。
- 保留审批人、接收对象、表单设置和无关数据。页面只能通过“提交”“发送”“发起审批”等动作写入时，交付可复制稿。用户要求保存时，可使用作用明确、独立的草稿保存功能，核验保存状态。
- 逐项回读周期、项目归属、标题、小结及适用的人日、单位和合计。页面失焦或操作中断时先重新读当前状态。仅核验了部分字段时，写明哪些已填、哪些还需手填。填写页验证通过后留给本人核对。区分已填未提交、已保存草稿和仅出稿。
- 遵守当前环境的资料访问和操作授权。只使用与任务有关的记录。交接内容和示例避免带出员工编号、账号、内网链接或其他可识别信息。对外提供示例时使用完全虚构的资料。
