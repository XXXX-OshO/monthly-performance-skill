# 月度绩效填报 Skill

把散在周报、项目记录和表格里的工作，整理成一份能直接复制的绩效稿。有界面操作能力时，也能代填表单，留给本人检查和提交。

- **钉钉**适合按业务线拆事项、写小结和分摊人日。
- **飞书**可按绩效自评或多维表格表单的实际字段出稿和代填。自评模板以所在组织配置为准。
- **其他系统**按页面字段适配。没有可操作的待提交页面时，生成逐字段填写稿。

钉钉的人日填报流程已实操。飞书和其他系统提供字段适配说明，尚未完成实际环境的端到端验证。

## 安装

- **WorkBuddy**：通过「添加技能 → 上传技能」导入 [技能 ZIP](monthly-performance.zip?raw=true)。[官方导入说明](https://cloud.tencent.com/document/product/1831/134432)
- **Codex 或其他支持 Agent Skills 的工具**：导入 `monthly-performance/` 文件夹，按平台方式启用。Codex 可用 `$monthly-performance` 调用。
- **只支持聊天或文件附件的工具**：把 `monthly-performance/SKILL.md` 和 `monthly-performance/references/form-adapters.md` 发给 Agent，请它按说明处理。代填依赖 Agent 已具备的网页、客户端操作或表单草稿能力。

## 使用者需要给什么

| 输入 | 提供方式 |
| --- | --- |
| 考核周期 | 写明年月或具体起止日 |
| 当期工作记录 | 可访问的链接、文件、截图或文字。团队资料请指出你的姓名标识或负责范围 |
| 业务线或绩效目标 | 按表单要求提供。有人日表时说明默认归属和例外，自评有既定目标时提供目标清单 |
| 总人日和约束 | 表单要求人日才需要。给应分摊总数、已确定的单项人日和单位 |
| 表单入口或字段 | 直接代填时先登录并打开本人填写页。只出稿时可提供表单字段、字数要求或脱敏截图 |

### 可直接复制的请求

> 用「月度绩效填报」帮我整理【考核周期】的绩效。工作记录在【链接、附件或摘录】，请看【工作表或我的负责范围】。  
> 绩效表按【业务线／绩效目标】填写，归属是【默认及例外】。若需要填人日，本期共【总人日】，已确定的项目天数是【可留空】，其余请估分并标明。  
> 我已打开【钉钉／飞书／其他系统】的本人填写页。填完请核对，留给我手动提交。无法代填时，请给可复制的稿件。

只需要文案时，把最后一段换成「请按【字段】出稿」。填到一半丢失时，可说「按上一版恢复填写」。
